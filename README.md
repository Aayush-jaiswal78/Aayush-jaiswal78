### 2. 🤖 Agentic AI Chatbot System

**Tech Stack:** Python · LangGraph · LangChain · FastAPI · Streamlit · Docker · GitHub Actions

An agentic chatbot that can decide when to respond directly and when to invoke tools to complete a task.

**Key Features**

- 🧩 LangGraph-based agent workflow
- 🔄 Conditional routing through LLM → Tool → Observation → LLM
- 🛠️ Custom tools for calculations, real-time weather, and timezone-aware time
- 🔌 LLM tool calling and external API integration
- ⚡ FastAPI backend with structured request and response models
- 🖥️ Streamlit-based conversational interface
- 🐳 Docker Compose for containerized application setup
- 🔁 GitHub Actions CI/CD for automated build and deployment workflows

**What I learned:** Agent orchestration, tool integration, multi-step decision-making, API design, containerization, and CI/CD automation.
